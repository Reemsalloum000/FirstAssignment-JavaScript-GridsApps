# FirstAssignment-JavaScript-GridsApps
This project includes 48 beginner-friendly JavaScript tasks designed to build core programming skills. It covers variables, loops, conditional statements, functions, and basic DOM manipulation.  🛠️ Developed as part of a training program at Gridsapps to strengthen hands-on experience with modern JavaScript concepts.
